## Security posture

This is a single-employer Node.js RPA daemon. The operator host environment is the root of trust: it holds gov.br credentials, persists Playwright cookies to `session.json`, and posts payroll close plus DAE download through axios. There is no multi-user app and no inbound business API. The only inbound HTTP surface is an optional health server. When `HEALTH_ENABLED=true`, source and existing tests show unauthenticated `GET /health` and `GET /metrics` returning Node version and job counters (confirmed, low). Remaining leads depend on deployment facts (bind address, `/tmp` sharing, file umask, Slack mrkdwn rendering, GitHub fork-secret policy, live eSocial error text).

### Unauthenticated GET /health and /metrics (low)

- **Fingerprint:** `src.health.js:unauthenticated-GET-health-metrics`
- **Source:** `src/health.js` (`startHealthServer` request listener, lines 79–99); started from `index.js` line 50.
- **Lower-trust principal:** an unauthenticated TCP client that can reach the health port, distinct from the operator who set `HEALTH_ENABLED=true`.
- **Reproduction (target-native, from committed tests):** set `HEALTH_ENABLED=true` and `HEALTH_PORT=0`, call `startHealthServer()`, then `http.get` `/health` and `/metrics` with empty headers. `tests/health.test.js` already records unauthenticated 200 with `nodeVersion` and `esocial_job_runs_total`.
- **Conditions:** `HEALTH_ENABLED` must be the string `true` (default false). Caller needs a TCP path to `HEALTH_PORT`. No credentials are required.
- **Result:** JSON includes `nodeVersion`, `lastJobRun`, `lastJobStatus`, `jobRunsTotal`; `/metrics` emits Prometheus counters. Not credentials, cookies, or DAE PDFs.
- **Impact / priority:** low/low. Opt-in flag; disclosure is telemetry and runtime version.
- **Smallest source fix:** require `HEALTH_TOKEN` when the server is enabled (fail closed if unset); reject requests without matching `Authorization: Bearer`; do not put Node version or job counters on an unauthenticated probe. Bind loopback by default.
